# Save The Baby

Story-driven Match-3 adventure and reusable puzzle game engine, built with Godot 4 and GDScript.

The product vision, campaign scope, gameplay, roadmap, release goals, and asset backlog are defined in [GAME_PLAN.md](GAME_PLAN.md). API maps document subsystem contracts. The animation folder's specific responsibilities are documented in [AnimationFolderResponsibity.md](scripts/animation/AnimationFolderResponsibity.md).
