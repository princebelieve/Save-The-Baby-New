# Candy Crush screen reference collection

Collected and visually inspected on 11 November 2026 for Save The Baby design
research. These are third-party reference images, not assets for use in the game.
Images and trademarks belong to their respective owners. Follow the source links
for original context. Screens from different years/variants do not constitute a
single recorded app session. Some examples are historical or promotional.
